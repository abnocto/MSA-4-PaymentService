# Реестр транзакций Saga

| Транзакция | Описание | Тип | Компенсация |
| :- | :- | :- | :- |
| CREATE_PAYMENT | Создает платеж в статусе "создан". | компенсируемая | FINALIZE_PAYMENT (платеж переходит в статус "отклонен") |
| AUTHORIZE_MONEY | Холдирует сумму на счете клиента (без реального списания). | компенсируемая | RELEASE_MONEY |
| CHECK_PAYMENT_ANTIFRAUD | Проверяет платеж и отвечает "разрешить", "запретить" или "ручная проверка". | повторяемая | - |
| CHECK_PAYMENT_AML | Проводит AML-проверку. | повторяемая | - |
| INITIATE_PAYMENT_MANUAL_CHECK | Ставит задачу оператору, если требует антифрод. | компенсируемая | CANCEL_PAYMENT_MANUAL_CHECK |
| CAPTURE_MONEY | Списывает захолдированную сумму на счет платформы. | необратимая (точка невозврата) | Компенсации нет, есть корректировка: REFUND_MONEY |
| TRANSFER_MONEY | Переводит сумму со счета платформы контрагенту. | повторяемая (по природе тоже необратимая, но в данном процессе идет после точки невозврата, поэтому в данном контексте скорее повторяемая) | - |
| CANCEL_PAYMENT_MANUAL_CHECK | Снимает задачу оператора. | повторяемая | - |
| RELEASE_MONEY | Снимает холд. | повторяемая | - |
| REFUND_MONEY | Возвращает списанную сумму с транзитного счета клиенту. | повторяемая | - |
| NOTIFY_SECURITY | Отправляет данные о заблокированной операции в систему безопасности для анализа. | повторяемая | - |
| NOTIFY_USER | Уведомляет клиента об итоге: платеж проведен, отклонен или деньги возвращены. | повторяемая | - |
| FINALIZE_PAYMENT | Переводит платеж в итоговый статус: "проведен", "отклонен" или "возвращен". | повторяемая | - |

## Порядок шагов

- Успех: CREATE_PAYMENT → AUTHORIZE_MONEY → CHECK_PAYMENT_ANTIFRAUD и CHECK_PAYMENT_AML (параллельно) → INITIATE_PAYMENT_MANUAL_CHECK (если нужна ручная проверка) → CAPTURE_MONEY → TRANSFER_MONEY → FINALIZE_PAYMENT → NOTIFY_USER.
- Отказ до точки невозврата: CANCEL_PAYMENT_MANUAL_CHECK (если нужно) → RELEASE_MONEY → NOTIFY_SECURITY (если отказали проверки) → FINALIZE_PAYMENT → NOTIFY_USER.
- Перевод не удался после точки невозврата: REFUND_MONEY → FINALIZE_PAYMENT → NOTIFY_USER.
